# Dự Án Website Cửa Hàng Văn Phòng Phẩm

Dự án phát triển **hệ thống quản lý** và *website bán hàng* văn phòng phẩm cho cửa hàng.

## Cơ Cấu Thư Mục

| Thư mục / File | Nội dung / Chức năng |
| :--- | :--- |
| `docs/` | Tài liệu dự án và quy trình nhập hàng |
| `media/` | Chứa hình ảnh, logo và bộ nhận diện thương hiệu |
| `data/` | Lưu trữ file dữ liệu Excel, đơn bán hàng |
| `logs/` | Nhật ký hệ thống và các báo cáo lỗi |
| `backup/` | Sao lưu các file quan trọng của hệ thống |
